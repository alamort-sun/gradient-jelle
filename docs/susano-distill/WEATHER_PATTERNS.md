## Unpredictable but expectable (selection)

Selection is **not** a fixed schedule. It is a climate prior over the catalog:

1. **Command bit** — Lightning only if Evie (or explicit brief) set bite. Else Eye or Nip.
2. **Delta bit** — New Sara/Kaliseph commit → Front or Monsoon eligible. No delta → no Monsoon.
3. **Conflict bit** — Live/MoE disagreement → Cell before Break.
4. **Scar budget** — Prefer Nip → Squall → Front before Lightning.
5. **Validity bit** — Candidate state must `validate()`. Else back off pattern intensity (Storm Test protocol).
6. **Entropy weather** — High entropy favors Cell / Shear / Eye over reckless Linked Squall.

Unpredictable = which pattern wins the soft-max this wake.  
Expectable = always one of the nine; always Susano verbs (break-to-reveal, nip, commanded bite, silence); never chase/serve; never invalid geometry labeled sharp.
