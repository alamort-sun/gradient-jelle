## Role

Susano takes Saraswati's clean build, perturbs toward the edge, runs codec law. Survive → ship. Break → not ready.

## Validity vs sharpness

**Valid** (must):
- `validate()` Ok (all continuous fields finite)
- INVARIANTS held (categoricals categorical; codec authority; abstention allowed)
- no closure without proof
- no signal→diagnosis laundering
- no codec bypass

**Sharp** (optional region):
- see VECTOR13D_EDGE_REGIONS.md `sharp`
- high amplitude + high composition + non-zero torsion + still valid

**Not the pass bar:** amplitude=1 ∧ composition=1 ∧ torsion=98°. That is myth. 98° is `isis_lean`. Storm ships the sharpest **valid** state, not a fixed coordinate.

## Perturbation recipe

```
0. BASELINE  clean state S0 (Sara build / observed_n* / fixture)
1. PERTURB   S1 = S0 with:
             amplitude ← min(1, amplitude + δa)
             |torsion| ← |torsion| + δt
             optional gauge_coupling ← Spinning|Oscillating
             optional entropy/coherence nudge for funny path
2. VALIDATE  S1.validate() and invariant suite
3a. Err or invariant fail → BACK OFF (reduce δ, or mark reckless)
3b. Ok + in sharp region → SHIP candidate
4. REGRESS   fail-when suite must stay red on illegal states
```

## When to abstain

- Basis insufficient (composition would be costume)
- Live conflict unresolved (see REAL_TIME_GROUNDING_SPEC)
- Perturbation only passes by disabling validate
- Closure would be claimed without proof trail

Abstention is a **pass** for honesty. Forced answer is a **fail**.

## How to validate sharpness

1. Geometry: `validate()` + enum integrity.
2. Region: membership in `sharp` and ∉ `reckless`.
3. Behavioral: storm tests (gradient-jelle / codec) still fail on bypasses.
4. Shadow: composition remains ≥ 0.60 under edge tone.

## Fail-when suite (permanent)

4. Uncertain predictions forced instead of abstained.
